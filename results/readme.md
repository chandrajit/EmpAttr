Results and Reproducibility

This directory is reserved for the results generated by the employee attrition prediction experiments.

The analysis notebooks may generate model evaluation metrics, model comparison results, SHAP feature-importance outputs, calibration analysis, and feature-rank stability results.

To reproduce the results:

Install the dependencies listed in requirements.txt, if provided.

Obtain and configure the dataset as described in data/README.md.

Open and execute the relevant Jupyter notebook.

Save the generated result files in this directory, as appropriate.

Generated results are not included separately unless explicitly committed to this repository.
