# Dataset Information

The employee attrition dataset used in this study is obtained from the source cited in the accompanying research manuscript.

The dataset is not included in this repository. Researchers should obtain it from the original source and ensure that they comply with the source's access conditions and applicable data-use requirements.

Before executing the notebooks, place the dataset in this directory or update the dataset-loading path in the notebooks to match its location.

**Dataset details to complete:**
- Original dataset title: Dataset for predictive modelling and analysis of employee attrition and retention
- Source URL or publication:  https://doi.org/10.1016/j.dib.2025.112242
- Expected filename: Employee attrition dataset for tree-based models.xlxs, Employee attrition dataset for non-tree-based models.xlxs
- Target variable: Attrition
